# Files+

Files+ is a cross-platform desktop app that organizes your files by category and name. Instead of manually sorting through cluttered folders, Files+ automatically groups your files so you can find and manage them faster.

## Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm

### Steps

1. Clone the repository:
```bash
   git clone https://github.com/kchandel-nj/files-plus.git
   cd files-plus
```

2. Install dependencies:
```bash
   npm install
```

3. Start the app in development mode:
```bash
   npm run dev
```

4. To build for production:
```bash
   npm run build
```

## Usage

Once the app is running:

1. Open Files+ — your files will be automatically scanned and grouped by category.
2. Browse categories to quickly locate files by type or name.
3. Use the **Settings** menu to customize appearance, manage storage, and configure general preferences.
